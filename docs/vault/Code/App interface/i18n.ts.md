# i18n.ts

Tous les **textes de l'interface** en français et en anglais (1 212 clés par langue), plus les fonctions de traduction et de mise en forme des dates et nombres. Fiche parente : [[Code de l'app (interface)]]. Règles d'écriture : [[Voix et ton]]. Réglage de langue : [[Paramètres de l'app]].

Tout ce qui suit est CONFIRMÉ (code de `staging`, 10/11, commit `ee77d4f`).

## Rôle et place dans l'ensemble
- Les composants n'appellent pas `translate` directement : ils prennent `t(key, vars)` dans [[store.tsx]], qui y lie la langue courante (`rago.lang`, anglais par défaut).
- Les textes du **compte** (profil, invitation et formulaire d'avis, erreurs du compte) ne sont **pas** ici : ils sont dans [[accountText.ts]] (67 clés), pour ne pas mélanger les deux fichiers.
- Les noms et descriptions des réglages ne sont pas ici non plus : ils viennent du catalogue ([[catalog.json]], champs `{ fr, en }`).
- La barre en jeu ([[Overlay.tsx]]) importe `translate` directement (elle n'a pas de store).

## Ce que le fichier expose
| Nom | Rôle |
|---|---|
| `type Key` | `keyof typeof fr` : la liste des clés est **celle du dictionnaire français** |
| `translate(lang, key, vars = {})` | texte traduit, avec pluriel et variables |
| `formatDate(lang, ts)` | jour et mois court (`fr-FR` ou `en-US`), ex. « 10 nov. » |
| `formatTime(lang, ts)` | l'heure (`HH:MM`) si c'est aujourd'hui, sinon date courte + heure |
| `formatNumber(lang, n, digits = 1)` | nombre avec exactement `digits` décimales, séparateurs de la langue |

Les dictionnaires `fr` et `en` sont des constantes internes ; `en` est typé `Record<Key, string>` : **TypeScript refuse de compiler si une clé française manque en anglais** (ou si l'anglais en a une de trop).

## Fonctionnement détaillé

### Traduction
1. `s = dicts[lang][key] ?? key` (une clé absente s'affiche telle quelle, ce qui ne peut arriver qu'avec une clé construite dynamiquement, ex. `block.${…}`).
2. **Pluriel** : si le texte contient `|`, il est découpé en `singulier|pluriel` et `vars.n` choisit :
   - français : pluriel si `n > 1` (0 et 1 au singulier) ;
   - anglais : pluriel si `n !== 1` ;
   - au singulier, si `n` vaut 0, le chiffre `1` écrit en toutes lettres dans le singulier est remplacé par `0` (« 0 réglage », pas « 1 réglage »).
   48 clés ont un pluriel.
3. **Variables** : chaque `{nom}` est remplacé par `vars.nom` (vide si absent).

## Ajouter un texte
1. Ajouter la clé dans `fr` (au bon endroit, près des clés de la même zone).
2. Ajouter **la même clé** dans `en` : sinon `npm run build` échoue (`tsc --noEmit`).
3. Pluriel : écrire `"{n} truc|{n} trucs"` et passer `{ n }`.
4. Dans le composant : `const { t } = useStore(); t("ma.cle", { n })`.
5. Respecter [[Voix et ton]] : tutoiement en français, phrases simples, pas de promesse de gain non vérifié.

## À savoir avant de modifier
- Une clé construite à la volée (`t(\`block.${x}\` as Key)`) échappe au contrôle de TypeScript : vérifier qu'elle existe dans les deux langues.
- Le site a ses propres textes ; un texte commun (prix, nombre de réglages) doit être changé aux deux endroits (voir [[Site]]).
- Le fichier fait plus de 2 000 lignes : chercher une clé avec `grep -n '"ma.cle"' app/src/lib/i18n.ts` (première occurrence = français, seconde = anglais).
