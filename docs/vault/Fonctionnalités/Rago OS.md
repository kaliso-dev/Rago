# Rago OS

Section « transformation Windows » demandée le 21/10 : un bouton qui habille le Windows du joueur aux couleurs de Rago, « full glassy », optimisé pour le jeu.

- **Principes non négociables** (Sofiene) : légalité (jamais d'ISO modifiée, jamais toucher à l'activation, pas le nom ni le logo « Windows »), réversibilité totale (valeurs d'origine sauvegardées, point de restauration, « Désactiver et tout restaurer »), aucun fichier système modifié.
- **v2** (PR #60, ouverte, base `claude/app-redesign-glass-z5m1c8`) : barre du haut, Dock, recherche Alt+Espace, centre de contrôle, « Dynamic Island », fond d'écran Rago, tout se cache en jeu. Composant « Rago Shell ».
- Exe de test livré le 21/10 hors CI (minutes GitHub Actions épuisées ce jour-là) : `rago-os/` du dossier partagé ([[Sources]]).
- **État** : Sofiene l'a lancé le 21/10 ; aucun retour de test depuis. À VÉRIFIER avant toute suite. Pas inclus dans la [[Version 1.2.1]].
