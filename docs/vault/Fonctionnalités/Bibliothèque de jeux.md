# Bibliothèque de jeux

Linear RAG-57. Arrivée en [[Version 1.2.0]]. Code : `games.rs`, `icon.rs`, page `Games.tsx`.

- Jeux détectés automatiquement, avec leur image officielle (demande de Sofiene du 17/10).
- Launchers détectés avec leur vraie icône : Steam, Epic, Riot, Battle.net, EA, Ubisoft, GOG, Rockstar, Minecraft Launcher, Lunar, Badlion, Feather, Prism, Modrinth, CurseForge, Xbox. Cherchés dans tous les comptes du PC.
- Minecraft Java : une seule tuile ; « Lancer avec » propose Lunar ou le launcher officiel et retient le choix.
- Un jeu reconnu reçoit son preset (voir [[Presets]]). **« Optimize and play »** (Premium) applique le preset puis lance le jeu ; les tweaks restent appliqués après.
- Gratuit : la bibliothèque. Premium : Optimize and play.

Liens : [[Barre en jeu]], [[Problèmes joueurs]] (curseur perdu après Optimize and play).
