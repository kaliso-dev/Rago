# Client Minecraft Rago

Projet **à part** de l'app [[App Windows]] : Rago crée **son propre client Minecraft et son launcher, avec ses cosmétiques**. Il est **en cours et va être lancé** (Sofiene, 01/11). Le travail se fait dans un projet Claude isolé, **pas dans ce dépôt** : ce vault n'en connaît que le principe.

- Statut : EN COURS (Sofiene, 01/11 : « c'est un projet qui est toujours en cours et qui va être lancé »).
- Lien avec l'optimiseur : même marque et même public (Minecraft PvP, voir [[Projet]] et [[Charte graphique]]). Comment les deux se parleront (compte, Premium, cosmétiques payants) : À VÉRIFIER.
- Date de lancement, nom public, technologies, où sont le code et les fichiers : À VÉRIFIER (à demander à Sofiene quand ce sujet revient).

## Ce qu'on en a vu dans les fils (OBSERVÉ)
- **29/10, vers 01:42 UTC** : dans un fil de vidéo, Sofiene a envoyé par erreur une liste de demandes pour le client (« Non oublie je me suis trompé », 01:46 ; un fil dédié ouvert par le coordinateur a été fermé aussitôt). Cette liste montre ce qu'il veut pour le client, à confirmer avec lui :
  - menu principal avec le logo animé et une vidéo de fond floutée, effet verre sur les boutons et le menu des mods sans changer le design ;
  - OptiFine intégré : « le dev de optifine m'a envoyé le reponse enfin il m'a dis qu'on peux directement integrer optifine donc c'est parfait » ;
  - un preset qui active tous les mods de performance, des optimisations comme Lunar ou Badlion, des mods de correction et d'animation, et des mods PvP, Bedwars et Hypixel, « chaque mod doit etre comme lunar et badlion configurable avancé ».
  Statut de ces demandes dans le projet du client : À VÉRIFIER.
- **10/11** : un dépôt privé séparé, `network-server-rago`, contient un **serveur Minecraft** (moteur de combat et de recul, lobby, practice, Bed Wars, mesures faites sur Hypixel, prix d'un pack de départ). Sofiene a décidé de le rendre public pour les minutes GitHub ([[CI GitHub Actions]]). Ce serveur fait-il partie du projet du client ? À VÉRIFIER.
