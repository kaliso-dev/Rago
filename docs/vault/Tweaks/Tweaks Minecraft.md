## Jeu

### Préréglage OptiFine `mc_optifine` 🔒
Écrit un préréglage OptiFine, Performance ou Qualité, dans les options de Minecraft ; ton ancien fichier est sauvegardé.
- Variantes : Performance (`performance`), Qualité (`quality`) ; par défaut `performance`.
- Gain : Performance peut nettement augmenter les FPS, mais seulement si tu joues avec OptiFine.
- Inconvénient : Performance rend le jeu moins joli : ciel, nuages, animations et particules coupés.
- Exécuté par du code Rust natif (`minecraft_optifine`), pas par un script.
