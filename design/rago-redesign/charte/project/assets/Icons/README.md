# Icons

The Lucide icons the app uses, 24px grid, 2px stroke, round caps and joins. The files are drawn in `ink-2` (#A1A1AA) so they show here; in the app inline the path data with `stroke: currentColor` and let the parent set `ink-2`, `ink`, `red` or `red-ink`.

File names are the app's own keys (`net`, `pad`, `ram`, `chev`…), which are not always the Lucide names.

`zap` means "applies without restart" and sits after a tile name; do not use it as decoration. The apply button now uses the printed `apply` icon.

Since 22/11 the menu, the big states and the apply button use the **Printed icons** group. These Lucide icons stay for controls: icons inside buttons, inputs, chips and the top bar.
