Hitreg profilepremium

Adjusts how your PC takes in game data, with hitreg profiles and a Default to undo it.

HitregConnection

Each profile changes how Windows handles incoming network data: how much room it makes for it, and whether it bundles small pieces together before passing them on. Pick the profile that suits you, such as the one made for Hypixel, or choose Default to put Windows back as it was. Keep expectations modest, because the server decides whether a hit counts and your ping matters far more. Some profiles can also slow down large downloads.
