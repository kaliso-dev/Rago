pour le développeur // community.js

  • Embeds : embeds: [{ color: 0xFF3B30, description, image: { url } }]. La mention <@id> reste dans content : une mention dans un embed ne notifie pas.
  • Boutons de lien (bienvenue) : components de type 2, style 5, vers /download et /account. Les adresses sortent du texte.
  • Bannières : trois PNG fixes, 1200 × 480, hébergés sur le site (/img/discord/). Pas d’image générée par membre : aucun module en plus.
  • /invites : la barre ▰▱ est du texte (10 cases), calculée sur le prochain palier. /growth, /partner-link et les messages d’erreur restent en texte : réservés au staff ou très courts.
  • Avatar du bot : png/rago-tile-512.png (plein cadre, Discord le rogne en rond). Le texte personnalisé DISCORD_WELCOME_TEXT va dans la description.
